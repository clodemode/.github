# .github

Organization-level defaults for **clodemode**.

- [`profile/README.md`](profile/README.md) — the page GitHub renders at
  [github.com/clodemode](https://github.com/clodemode).
- [`profile/banner.svg`](profile/banner.svg) — masthead, drawn in the
  [clodemode.com](https://clodemode.com) palette.

Editing `profile/README.md` changes the organization's public front page immediately.
